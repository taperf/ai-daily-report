### Basis Cofounder Mitch Troyanovsky — 如何构建长周期 AI Agent（MAD Podcast）

Mitch Troyanovsky 在这期 MAD Podcast 中分享了 Basis 构建长周期自主 agent 的核心方法论。Basis 是一家独角兽 AI 公司，其 agent 可以自主运行数小时甚至数天完成复杂任务，比如端到端准备整个税务申报。

**核心观点：**
- **Agent 的本质**：LLM 拥有巨大的工作记忆，但默认没有短期或长期记忆。长周期 agent 的核心挑战是在超出上下文窗口后如何保持连贯性。
- **过程 vs 结果**：仅依赖可验证的结果（outcome）是不够的。100 次评估全通过也不意味着能泛化到真实世界。Basis 的做法是定义"行为规范"（behavior specs）——用 markdown 文件写下期望 agent 如何行事，不仅用于评判 agent，也用于对齐团队内部对产品行为的共识。
- **人类组织的启发**：人类已经习惯与非确定性系统（即同事）协作。公司和流程本质上就是设计如何让非确定性实体协调解决问题——这正是 agent 设计的核心。
- **编码之外的世界**：编码 agent 成功的原因不仅在于可验证奖励，还在于运行时可验证、成本极低、文本属性强。但真实世界任务（如会计）缺乏这些条件——数据稀缺、反馈循环长（一个税务申报可能需要 20+ 小时人工工作量）、对错边界模糊。
- **开源项目**：Basis 与 Brain Trust 合作开源了行为规范标准，旨在让行业共同建立 agent 行为评估的通用语言。

Mitch Troyanovsky, cofounder of Basis, shares lessons on building long-horizon autonomous agents. Basis builds agents for end-to-end accounting work, where agents operate autonomously for hours or days. His core insight: LLMs have large working memories but no short-term or long-term memory by default. The key challenge is maintaining coherence beyond the context window. Outcome-only verification is insufficient — 100 passing evals doesn't generalize to production. Basis defines "behavior specs" in markdown files that specify how agents should behave, serving both as evaluation rubrics and team alignment tools. Humans already work with non-deterministic systems (their coworkers), and organizational design offers lessons for agent architecture. Coding agents succeeded not just because of verifiable rewards, but because code is cheap to verify at runtime and highly text-based. Real-world tasks like accounting face data scarcity, long feedback loops (20+ hours of human work per tax return), and ambiguous correctness boundaries. Basis open-sourced a behavior spec standard with Brain Trust to help the industry develop shared evaluation language.

### Peter Yang — 拆解 X 的 AI Slop 对抗算法

Peter Yang 分析了 X 开源算法中对抗 AI 垃圾内容的机制。X 使用一个叫 TweetSpamBot 的行为模型，分析用户最近 512 个动作，识别发帖爆发、引用推文模式、时间规律等信号。但 Peter 指出关键缺口：这个模型不读取实际内容。这意味着一个成熟的 AI 内容工厂仍然可以全天候运作——找到爆款帖，用固定模板引用转发，每天重复 10+ 次。他认为如果 X 不想变成 LinkedIn，就需要关注那些反复将无关爆款帖变成同质化引用推文的高频账号。

Peter Yang analyzes X's open-source algorithm for fighting AI slop. X uses a behavioral model called TweetSpamBot that analyzes up to 512 recent account actions for signals like posting bursts and quote-tweet patterns. But the gap is that the model doesn't read actual post content. A sophisticated AI content mill can still operate all day: find viral posts, quote-tweet with the same template (hook → numbers → backstory → takeaway), repeat 10+ times daily across unrelated topics. Yang argues X needs to target accounts that repeatedly turn unrelated viral posts into templated quote-tweet slop at high volume.
