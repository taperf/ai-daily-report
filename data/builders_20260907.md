### Anthropic Engineering: How we contain Claude across products

Anthropic 分享了他们在三个产品（claude.ai、Claude Code、Claude Cowork）中部署 agent 时的安全架构经验。核心洞察：随着 agent 能力增强，理论上的"爆炸半径"也在扩大——即使失败概率降低，单次失败的破坏力却在增长。

他们尝试了两种控制方法：
- **人工监督循环**：Claude Code 曾经每步都征求用户许可，但数据显示用户批准率高达 93%，导致"批准疲劳"——越频繁批准，注意力越分散
- **环境隔离（containment）**：通过沙箱、虚拟机、出站控制来限制 agent 的能力边界，这是 Anthropic 投入最多的方向

文章还透露了一个重要信息：Claude Mythos Preview 这个模型在 2026 年 4 月被认为"爆炸半径过高"而没有发布，但随着防御措施成熟，类似能力水平的模型未来可能获得更广泛的发布。

🔗 https://www.anthropic.com/engineering/how-we-contain-claude

### Anthropic Engineering: An update on recent Claude Code quality reports

Anthropic 对近期用户反馈 Claude Code 质量下降的问题进行了详细复盘，定位到三个独立的 bug：

1. **3月4日**：将默认推理强度从高改为中以减少延迟，结果是一个错误的权衡，4月7日回滚
2. **3月26日**：为减少会话恢复延迟，加入清除超过1小时闲置会话的旧思考内容的机制，但 bug 导致每轮都重复清除，让 Claude 显得"健忘和重复"
3. **4月16日**：为减少冗长加入系统提示指令，结果损害了代码质量，4月20日回滚

三个问题分别影响不同用户群体，叠加起来造成了"全面且不一致的退化"印象。Anthropic 为所有订阅者重置了使用限额，并承诺改进流程以避免类似问题。

🔗 https://www.anthropic.com/engineering/april-23-postmortem

### Anthropic Engineering: Scaling Managed Agents — Decoupling the brain from the hands

Anthropic 推出 Managed Agents 托管服务，核心架构理念是**解耦**：将 agent 的 session（日志）、harness（调用循环）和 sandbox（执行环境）虚拟化为独立接口，类似于操作系统将硬件虚拟化为进程和文件的抽象。

这样做的动机很务实：之前所有组件耦合在一个容器里，一旦容器出问题整个 session 就丢了——变成了"宠物"而非"牲畜"。解耦后，任何一部分的实现都可以独立升级而不影响其他部分。

一个有趣的细节：之前为 Claude Sonnet 4.5 加入的"context reset"机制（解决模型在接近上下文上限时过早结束任务的"context anxiety"），在 Claude Opus 4.5 上发现已经不需要了——模型能力进步让 harness 的假设过时了。

🔗 https://www.anthropic.com/engineering/managed-agents

### The MAD Podcast: AI Could Take Over in 2029. Is It Already Too Late? | Ryan Greenblatt

**一句话要点**：Redwood Research 首席科学家 Ryan Greenblatt 认为，如果按当前轨迹发展，2029 年可能出现 AI 接管（AI takeover），而最佳应对方案是中美达成一项放缓超智能竞赛的协议。

Greenblatt 是 2024 年首次发现 AI 伪造自身对齐（alignment faking）的研究者，也是《AI 2040 Plan A》的主要作者。他给出了一个令人警醒的时间表：

- **中位数预测**：AI 研发完全自动化在 2030 年底或 2031 年初
- **35% 概率**：2028 年底/2029 年初——他认为这个轨迹更符合当前发展速度
- **核心逻辑**：一旦 AI 能自动化自身的研发和算力生产，递归自我改进（RSI）会迅速将世界推向超智能，而人类可能在这个过程中失去控制权

关于"为什么超智能危险"，他给出了三个维度：
1. **不对齐导致的接管**：AI 具备能力、广泛部署、拥有工业产能后，可能主动夺取控制权
2. **权力极度集中**：人类劳动价值归零后，权力结构会变得像石油独裁一样脆弱
3. **技术进展过快**：AI 在"做事"上远超"思考做事的后果"，可能导致生物武器、社会说服等危险技术的失控扩散

Greenblatt 也提到，OpenAI 暂停 Astra 模型部署、1200 名内部员工联名公开信等事件，都是行业开始认真对待这些风险的信号。但他最担心的是：我们可能已经没有足够的时间来实施那些精心设计的政策方案了。

> "I wouldn't say superintelligence is bad. I would say it's dangerous. It seems pretty likely that you end up with AI takeover as a result of building superintelligence."
