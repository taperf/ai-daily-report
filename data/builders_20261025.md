### Guillermo Rauch（Vercel CEO）

Vercel CEO Guillermo Rauch provided the clearest technical breakdown of OpenAI's newly disclosed timing attack between agents sharing a VM, describing it as a "noisy neighbor" attack: one agent can make enough noise through CPU caches that another detects it by timing its own computation. He notes this attack class has been known since at least 2015 with no complete solution, and the only full fix, running each agent on dedicated hardware, carries significant economic consequences. Vercel Sandbox has deployed practical mitigations plus always-on monitoring and red-teaming.

Vercel CEO Guillermo Rauch 对 OpenAI 最新披露的同机 agent 侧信道攻击做了迄今最清晰的技术拆解，并将其形容为“吵闹邻居”攻击：同一台机器上的一个 agent 通过 CPU 缓存制造足够的“噪音”，另一个 agent 就能通过给自己计算的计时来探测到。他指出这类攻击至少从 2015 年就已为人所知，至今没有彻底解法，唯一完整的方案是每个 agent 跑在专属硬件上，而这有严重的经济成本。Vercel Sandbox 已部署了所有可行的缓解措施，并辅以全天候监控和红队演练。

### No Priors：Democratizing Security for the Agentic Web（嘉宾：Cloudflare CTO Dane Knecht）

**The Takeaway:** AI is simultaneously detonating an Internet-wide security crisis and serving as the only tool that can fix it at scale. Brace for roughly eighteen months where security eats engineering time, then software productivity rebounds.

Cloudflare CTO Dane Knecht oversees infrastructure that much of the web runs behind, which gives him an unfiltered view of an exponential shift: vulnerability reports in code development environments have surged over the past three to six months. Internet-shaking bugs like Log4j or Shellshock used to arrive maybe once a year; now they are constant. His examples are striking: a key protecting TLS/WebPKI was found seeded with the number "4," and OpenAI researchers recovered the seeds for NIST elliptic curves from the year 2000. The attacker landscape has flattened, too. Many recent major vulnerabilities came not from nation-states but from high school kids pointing agents at bug-bounty targets, what the hosts dubbed "agent kitties."

His operational forecast: over 50% of engineering time will temporarily flow to security, echoing Greg Brockman's prediction that by 2027 security token spend will rival engineering spend. But he expects the crunch to be a short transition, after which agents that surveyed the codebase return productivity to building. The defense playbook starts with first principles, since today's AI tends to add complexity rather than reduce it: shrink attack surface, use safer languages and formal verification, and encode engineering principles into documents agents can follow (Cloudflare distills its RFCs into a "Codex" of tenets). He is expanding from one red team to four or five.

The second theme is the business layer of an agent web. Humans and agents currently "ride the same rails" on an Internet designed for human browsing speeds, and he expects parallel human and machine webs to emerge. Cloudflare is building the payment infrastructure for that world: a content monetization gateway with agent wallets, a stablecoin for micropayments, x402-style payment rails, and a project with OpenAI called signals to help agents discover new content instead of endlessly crawling. On the inside, Cloudflare OS, the company's internal AI platform, is used more by go-to-market and G&A teams than engineers. His talent philosophy has shifted accordingly: about 1,000 interns a year for a 5,000-person company, because AI-native interns adopt fastest; token governance runs on gentle nudges (300 per day triggers an email, 500 reaches the manager, 1,000 reaches a VP); and the biggest hiring red flag is simple, a curious person who does not use AI in their personal life.

**核心要点：** AI 正在同时引爆一场波及整个互联网的安全危机，又是唯一能大规模解决它的工具。接下来约十八个月，安全将吞噬大量工程时间，之后软件生产力会反弹。

Cloudflare CTO Dane Knecht 掌管着大半个互联网赖以运转的基础设施，这让他对一场指数级变化看得一清二楚：过去三到六个月，代码开发环境中的漏洞报告数量暴涨。像 Log4j、Shellshock 这种震动全网的漏洞以前大约一年出现一次，现在层出不穷。他举的例子相当震撼：一个保护 TLS/WebPKI 的密钥，随机种子被发现是数字“4”；OpenAI 研究人员甚至复原了 2000 年 NIST 椭圆曲线的种子。攻击者的门槛也被抹平了：近期不少重大漏洞并非出自国家级黑客，而是高中生把 agent 指向漏洞赏金目标做出来的，主持人给他们起了个名字，“agent kitties（agent 版脚本小子）”。

他的运营预判是：短期内超过 50% 的工程时间将流向安全，这与 Greg Brockman 上周的预测呼应，即到 2027 年花在安全上的 token 开销将与工程开发相当。但他认为这种紧绷只是短暂过渡，等 agent 扫完存量代码，生产力就会回到“造新东西”上。防御打法要回到第一性原理，因为今天的 AI 天生爱堆复杂度而不是做减法：缩小攻击面、采用更安全的语言和形式化验证、把工程原则沉淀成 agent 能遵循的文档（Cloudflare 把内部 RFC 提炼成一套名为“Codex”的行为准则），并把红队从一支扩到四五支。

第二个主题是 agent 互联网的商业层。人类和 agent 目前在为人类浏览速度设计的同一条轨道上“混跑”，他预计未来会出现平行的人类网络和机器网络。Cloudflare 正在为那个世界铺设支付基础设施：带 agent 钱包的内容变现网关、用于微支付的稳定币、x402 式支付通道，以及与 OpenAI 合作的 signals 项目，让 agent 主动发现新内容而不是无休止爬取。在公司内部，Cloudflare OS 这个 AI 平台的市场和职能团队用得比工程师还多。他的人才哲学也随之改变：5000 人的公司一年招约 1000 名实习生，因为 AI 原生实习生上手最快；token 治理靠柔性提醒（每天用到 300 收邮件提示，500 通知经理，1000 通知 VP）；而招聘中最大的红旗很简单，一个有好奇心的人却在私人生活中完全不用 AI。
