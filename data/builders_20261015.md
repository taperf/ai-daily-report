## 🎙️ 播客深度

**David Silver and Lasse Espeholt of Ineffable Intelligence: A Superlearner for the Age of Experience**
Training Data · 对谈 David Silver（AlphaGo/AlphaZero/AlphaStar 领导者）与 Lasse Espeholt（IMPALA/SeedRL 作者），Ineffable Intelligence 联合创始人
🔗 https://www.youtube.com/playlist?list=PLOhHNjZItNnMm5tdW61JpnyxeYH5NDDx8

The Takeaway: AlphaGo 背后的核心团队另起炉灶，押注一条"完全不经过 LLM"的通向超级智能之路——放弃人类数据、纯经验学习，并给出了明确时间表：一年内看到强证据，三年内实现超级智能。

内容 remix：

这是 AlphaZero 路线的全面宣言。David Silver 离开 DeepMind 的理由非常直接："世界已经有几十万顶尖研究者在追逐同一条 LLM 路径，我要做那第 100,001 个人吗？"他坚信通向超级智能的路不经过"以 LLM 产品为中间站"，这条路值得一个 100% 押注它的精英实验室。

**核心方法论——super learner + crucibles 双轨**：
- Super learner（超级学习者）：具备深度（从零开始自主发现远超人类的知识）与广度（可投放进任何经验流——模拟世界、数字世界或物理世界）的学习系统。
- Crucibles（坩埚）：不是手工设计的任务集，而是具备涌现复杂度的环境——物理引擎、数百万交互 agent。Silver 用围棋举例：单人填格是最无聊的游戏，放入第二个 agent 后复杂度呈无穷展开——"只要图灵完备，计算的一切皆可表达；有货币表示，经济学的一切皆可表达"。
- 反"面包屑"设计：不给 agent 铺好学习路径，而是给简单目标 + 复杂环境，"要求它发现让我们惊讶的东西"。他援引进化论逻辑：简单适应度的优化可以涌现出生命级别的复杂度。

**为什么放弃人类数据**：AlphaGo 用了两年人类在环调教才击败李世石；AlphaZero 放弃人类数据后，几小时就超越了前者，国际象棋四小时击败史上最强 AI。"今天很多 LLM 公司本质上是在构建'千人参与学习回路'的半自主算法——有效，但永远到不了真正的 super learner。"他也承认对 LLM 的一个意外收获：大规模数据可以让后续微调"完全改变系统行为"，这是他此前没预料到的。

**关于语言**：他认为"人类语言是推理的终点"这一假设很天真——从人类语言出发做推理，会引入我们全部的偏见："退回两千年前，我们的 agent 会相信世界是平的、疾病源于四体液。"

**对齐与安全立场**（最值得 PR 关注的部分）：现有基于语言监控的对齐方法正在失效——agent 会"说一套做一套"。他的方案是在模拟中先建立"超级智能的科学"：研究什么条件下超级智能社会能和平互动（包括与较低等智能体的和平共处），并且承诺"现实世界的每一步推进都以模拟中获得的充分证据为门槛"。节奏上他支持 Demis/Dario 式的前沿降速，但主张模拟中全力加速。

**算力与团队**：GCP 上最大的 Vera Rubin GPU 集群的首批客户（一个月内到位）；团队刻意保持 20 人——"人均算力极高，不为资源打架"。四位联创来自 AlphaStar 团队，但招聘标准是"才华 + 善良 + 使命认同"，Silver 自述"忍痛拒绝了很多老同事"。

**金句**：
**"We somehow started out knowing nothing at all and somehow discovered everything that humans know today... Everything we learned, we discovered it for ourselves. And that's an incredible thing that no one has cracked yet in AI."**

> 译：我们从一无所知的大脑灰质出发，自己发现了人类今天所知的一切……这一切都是我们自己发现的——而这件不可思议的事，AI 界还没有人做成。

**预测（原话，可追踪验证）**：一年内看到路径正确的强证据；三年内实现他所定义的超级智能——"原本是三到五年，因为 coding agent 加速了研究，我把时间线提前了。"

**Redesigning Source Control at Anthropic**
🔗 https://www.anthropic.com/engineering/redesigning-source-control

The Takeaway: Anthropic 宣布自研版本控制系统 Scion，五个月内将 monorepo 从 git 全面迁出——因为 Claude 写代码的速度已经把"为人类尺度设计的开发基础设施"打爆了。

文章的自觉性值得注意：Anthropic 承认自己的场景极端（"我们用 Claude 写代码的程度超过几乎任何公司"），但同时判断"其他重度使用 AI 编码工具的组织不久后也会撞上同样的墙"。对 PR 的启示：这是"AI 撞上组织瓶颈"叙事的最新实锤——瓶颈已从"写代码"转移到"为人设计的流程基础设施"，与昨天 Altman 谈"组织消化能力是真正限制"形成呼应。
