## Podcast: Training Data — Parallel's Parag Agrawal: Building a New Web for AI Agents

**The Takeaway:** Parag Agrawal, former Twitter CEO, is building Parallel — an agentic search engine designed from first principles for AI agents rather than humans. His core thesis: human click data is a bug, and the future of search belongs to agent feedback loops.

Agrawal frames web search as a "billion-to-billion matching problem" — hundreds of billions of pages against hundreds of billions of queries. Google's dominance rested on two moats: the infrastructure to crawl and index at web scale, and proprietary feedback data (clicks, human ratings). Parallel's bet is that both moats are eroding. LLMs can now generate high-quality ratings far cheaper than human labelers. And agents, unlike lazy humans who type "two incomplete words with a typo," submit well-specified, longer, typo-free queries — fundamentally changing the search optimization problem.

The business model question is equally bold. Agrawal argues that ad-based monetization, which subsidized free content for humans, breaks down when agents replace eyeballs. Content owners can't monetize agent visits, leading to a tragedy of the commons where quality content gets paywalled or withdrawn. Parallel's proposed solution: **Shapley-value-based pricing** — a game-theoretic framework to fairly attribute and pay for the incremental value each content source contributes to an agent's output. He claims the macro math works: if AI inference spending allocates even 2-10% to web data, that's larger than most current web content business models outside walled gardens.

On partnerships, Agrawal announced that Parallel is now a **search and grounding provider for Google Cloud's enterprise agent APIs** — a notable win for a startup competing in search. He also described three stages of the "agentic web": (1) agents using web search as a tool, (2) sophisticated multi-agent systems with sub-agents, and (3) the web shifting from pull to push — where agents subscribe to changes and trigger work automatically.

The interview is long but rich. Agrawal's combination of deep systems thinking, game-theoretic economics, and operational clarity makes this one of the more intellectually dense AI builder conversations this year.

**核心观点：** 前 Twitter CEO Parag Agrawal 正在打造 Parallel——一个从零开始为 AI agent 而非人类设计的 agentic 搜索引擎。他的核心论点：人类点击数据是个 bug，搜索的未来属于 agent 反馈循环。

Agrawal 将网页搜索框定为"十亿对十亿的匹配问题"——数千亿页面对阵数千亿查询。Google 的统治建立在两道护城河之上：网络规模爬取和索引的基础设施能力，以及专有反馈数据（点击、人工评分）。Parallel 的赌注是这两道护城河都在被侵蚀。LLM 现在可以比人工标注者更便宜地生成高质量评分。而且 agent 不像懒得打字的"两个不完整单词加一个拼写错误"的人类——它们提交的是精确、更长、无拼写错误的查询，从根本上改变了搜索优化问题。

商业模式问题同样大胆。Agrawal 认为，当 agent 取代眼球时，支撑人类免费内容的广告变现模式会崩溃。内容所有者无法从 agent 访问中获利，导致公地悲剧：优质内容被设 paywall 或撤回。Parallel 提出的解决方案是：**基于 Shapley value 的定价**——一种博弈论框架，公平地归因和支付每个内容源对 agent 输出的增量价值。他声称宏观数学成立：如果 AI 推理支出将 2-10% 分配给网页数据，那就超过了围墙花园之外大多数现有网页内容商业模式的总和。

在合作方面，Agrawal 宣布 Parallel 现在成为 **Google Cloud 企业 agent API 的搜索和 grounding 提供商**——一家在搜索领域竞争的创业公司能拿下这样的合作相当不易。他还描述了"agentic web"的三个阶段：（1）agent 将网页搜索作为工具使用，（2）带有子 agent 的复杂多 agent 系统，（3）网络从 pull 转向 push——agent 订阅变化并自动触发工作。

这场采访很长但信息量极大。Agrawal 将深度系统思维、博弈论经济学和运营清晰度结合在一起的对话，是今年最富智识密度的 AI builder 对谈之一。
