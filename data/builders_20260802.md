## 📝 产品动态

### Claude Code 正式支持 Artifacts

**Claude Blog** · 2026年6月18日

Anthropic 为 Claude Code 上线了 **Artifacts** 功能，将其会话中的工作成果转化为可实时更新、可分享的交互式页面。

**Artifacts 的核心能力：**
- **自动生成**：无需手动整理，Claude Code 直接从会话上下文（代码库、连接器、对话内容）中构建页面
- **实时刷新**：页面在浏览器中自动更新，每次发布都是新版本，保留完整版本历史
- **典型场景**：PR 走查报告、系统架构说明、数据仪表盘、发布检查清单
- **隐私保护**：默认仅作者可见，可按组织/角色范围分享，不可公开

**实际使用案例：**
一位工程师在站会前启动事故调查，Claude Code 分析日志后生成 Artifact —— 包含时间线、可疑提交和错误率图表。她将链接分享给团队，站会开始时 Claude 已更新了两次。团队无需「听代理汇报」，所有人看到的是同一视图。
