### Training Data: Parallel's Parag Agrawal — Building a New Web for AI Agents

**The Takeaway:** The economics of the human web — built on ads, human attention, and click data — will not survive the agentic transition. Parag Agrawal, former Twitter CEO and now founder of Parallel, is building the infrastructure and business model for a "parallel web" designed specifically for AI agents, not humans.

**核心要点：** 建立在广告、人类注意力和点击数据之上的人类网络经济学将无法在代理化转型中存活。Twitter 前 CEO、Parallel 创始人 Parag Agrawal 正在专门为 AI 代理（而非人类）构建"平行网络"的基础设施和商业模式。

Parag Agrawal argues that human click data is a bug, not a feature, for agentic search. Agents don't need fast-loading pages with information above the fold — they need the most authoritative source, even if it's page 73 of a PDF. This fundamentally breaks the SEO-driven content economy that has dominated the web for two decades. Parallel's approach replaces human feedback with agent feedback for search ranking, and uses Shapley values from game theory to determine fair attribution and payment for content owners — differential pricing based on both content quality and the value of the work being done with it.

Parag Agrawal 认为，对于代理搜索来说，人类点击数据是一个 bug，而非功能。代理不需要信息放在首屏的快速加载页面 — 它们需要最权威的来源，即使那是 PDF 的第73页。这从根本上打破了两十年来主导网络的 SEO 驱动内容经济。Parallel 的方法用代理反馈取代人类反馈进行搜索排名，并使用博弈论中的 Shapley 值来确定内容所有者的公平归因和报酬 — 基于内容质量和所从事工作的价值进行差别定价。

Parallel is already partnered with Google Cloud as a search and grounding provider for enterprise agent APIs. Agrawal's vision extends to three levels: simple agents using web search as a tool, sophisticated multi-agent systems with sub-agents, and ultimately a "push" web where agents monitor changes and trigger actions automatically — what he calls "the web goes from pull to push."

Parallel 已经与 Google Cloud 合作，作为企业代理 API 的搜索和 grounding 提供商。Agrawal 的愿景分为三个层次：将网络搜索作为工具的简单代理、带有子代理的复杂多代理系统，最终是一个"推送"网络 — 代理监控变化并自动触发行动 — 他称之为"网络从拉取变为推送"。
