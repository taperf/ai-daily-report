### Box CEO Aaron Levie

**Aaron Levie 给出一个反直觉判断：AI 带来的生产率跃升不是 20%、30%，而是比 AI 之前高出 1 到 2 个数量级，而且这道差距不会随时间收敛。** 他把结果归因于几个前提的叠加：合适的 harness、对业务域的深度理解、相对较新的代码库、同时调度多个 agent 的熟练度，以及一条几乎无摩擦的测试与部署链路。他的推论与直觉相反——按常理 AI 应该拉平差距，但现实是「你过去积累的深度，加上现在愿意换一种做法的意愿，会带来疯狂的杠杆」，而且随着模型承接更大更难的任务，这个杠杆还在复利。他认为当前效应在软件工程最明显，但同样会扩散到科学、AEC（建筑与工程）、金融、网络安全等对 computer-use 敏感的领域。

**他还补了一个常被忽略的基础设施视角：AI agent 的推理可以跑在任何地方。** 因为 AI 是少数对用户侧延迟不那么敏感的技术。长时运行的 agent 会成为常态，任务可以发到远端「AI 工厂」算完再回传；数据加密流入、被 agent 处理完即可丢弃，不必长期驻留，于是推理可以被当成「临时系统」。推论很直接：AI 数据中心的选址自由度因此被打开，这是愿意接住机会的州和国家的经济红利，也是放弃机会者的损失。

### No Priors — Tokenization, Agentic Trading, Harmonic: Robinhood's Mission to Expand Ownership with CEO Vlad Tenev

**一句话结论**：Vlad Tenev 的判断是，agent 替人交易已经跨过概念验证——15 万客户开通 agentic 交易账户，工具调用量达到每天 3000 万次；但这件事长期的社会后果，取决于普通人能不能分享 AI 创造的财富。

Vlad Tenev 是 Robinhood 创始人兼 CEO，数学背景出身，在 Terence Tao（陶哲轩）门下读过书，也做过高频交易。他把 Robinhood 定义为一家「所有权（ownership）公司」，并用一段很个人化的经历解释原因：他在 1980 年代末生于东欧，亲身经历过保加利亚那种「每隔几个月就往货币上加零」的恶性通胀。他祖父是船厂医生，一发工资就去港口把现金换成铜锅——那是他人生中见到的第一种真实世界资产。

正是这段经历形成了 Tenev 对当前 AI 的核心批评。他不喜欢这一波 AI 解数学题的姿态：「太中心化了，就是 AI 公司带着巨大的数据中心、员工用秘密模型把活全干完。」他认为即使结果是证明了纳维-斯托克斯方程或黎曼猜想的局部，如果它出自某家公司黑箱里的机房，社会不会接受；如果出自一个普通人手里的工具，社会会庆祝。他联合创办的 Harmonic 去年做出的模型 Aristotle 在国际数学奥林匹克上拿到金牌，之后向公众开放，被用来攻克 Erdos 难题并产出新结果。

在 Robinhood 一侧，他把代币化讲成「稳定币的推广」：把股票、私募股权、艺术品装进一个盒子，对盒子铸造和销毁 token，底层资产照旧托管在传统机构，token 可以在链上自由流转、拆分、被组合。今年他们重启了完全 DeFi 化的股票 token，并推出为真实世界资产设计的 Robinhood Chain，开发者已经把它当乐高积木玩——股票 token 配 meme 币、配 NFT 这类组合，他自己都没预料到会长这么快。

Agentic 交易方面他给的数字很硬：15 万账户、每天 3000 万次工具调用；随后又推出 Robinhood Agents，把 harness 和整个 UI 搬进 Robinhood 账户，形态上类似 Claude Code 或 Codex，但为交易优化——可以跑循环、每天执行策略、做组合再平衡，还有 agent app store（比如接卫星数据去数零售商停车场里的车）。他对「人人都是高频交易者会不会压垮基础设施」的回应是分层拆解：从自家系统，到 Citadel、Jane Street 这类做市商，再到交易所，过去二十年都已为算法交易优化过；目前 agent 交易占比仍不高，所以「我们会先看到预警」。风控上的做法是隔离：agent 必须开独立账户，资金单独划入，默认每笔交易需要人工批准。

他最后那段对比 AI 与加密，是整期最值得琢磨的部分：加密在 2022、2023 年让很多人亏钱，但 2024 年这批人依然全力出动、影响了大选，任何监管越界的苗头都会遭到猛烈反击——因为加密从一开始就是被个体广泛持有的。AI 恰恰相反，头部公司全是私有公司，普通人拿不到敞口，「那人们为什么要欢迎数据中心？我从中得不到任何经济好处，它威胁我的饭碗、吵我的社区」。他的解法是 Robinhood Ventures：用 IPO 渠道向散户募资再投私募（一期含 OpenAI、Crusoe 等），二期与 YC 合作投种子和 A 轮，基金本身在纽交所像股票一样交易。

> 「我一直在跟那些公司里的人说，如果你们找几位数学家合作，情况会好得多——不至于看起来像有一个黑暗的数据中心未来，一家公司要做完全部的科学发现。」
