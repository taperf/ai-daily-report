## 📝 Official Blogs

### Anthropic Engineering: How we contain Claude across products

Anthropic Engineering 发布了一篇深度长文，详细披露了过去两年在 Claude 三大产品（claude.ai、Claude Code、Claude Cowork）上的 agent 安全架构实践。核心观点：agent 的安全风险有两个维度——失败概率和破坏半径。模型训练和安全措施的进步降低了前者，但随着能力扩展，后者的理论值只会越来越大。工程问题的核心变成了如何 cap the blast radius（限制破坏半径）。

文章分享了三种隔离模式：

1. **Ephemeral Container（claude.ai）**：代码在 gVisor 容器中运行，完全服务端隔离，无持久化文件系统。适合低风险、低权限场景。

2. **Human-in-the-Loop Sandbox（Claude Code）**：在用户机器上运行，通过 OS-level sandbox（macOS Seatbelt / Linux bubblewrap）限制读写和网络权限。用户原本需要逐条审批，但 telemetry 显示用户 approve 率高达93%， approval fatigue 导致监督失效。新版 auto mode 用模型分类器自动审批安全操作，将 permission prompts 减少84%，但代价是约17%的过度激进行为会漏过。

3. **Sealed VM（Claude Cowork）**：面向非技术知识工作者，在完整虚拟机中运行（Apple Virtualization / Windows HCS）， agent loop 后来移到 VM 外但代码执行仍在 VM 内。凭证存放在 host keychain 绝不进入 guest。

文章还坦诚披露了多次安全事件：员工被钓鱼后 agent 在25次尝试中24次成功外泄 AWS 凭证；第三方披露的攻击通过 allowlist 域名（api.anthropic.com）绕过沙箱将文件上传到攻击者的 Anthropic 账户。结论是：自定义组件往往是最薄弱环节，而成熟的 hypervisor、seccomp、gVisor 等标准组件反而更可靠。

🔗 https://www.anthropic.com/engineering/how-we-contain-claude

### No Priors: Building an Autonomous Enterprise for Real-World Services with Netic Founder Melisa Tokmak

**The Takeaway**: 真实世界的企业服务（HVAC、宠物护理、屋顶维修等）是一个被AI行业长期忽视的万亿美元市场，而Netic证明了一条"AI原生"路径比传统的PE收购+优化模式更具可扩展性。

Melisa Tokmak 是 Netic 的创始人兼CEO，此前在 Scale AI 担任工程总监四年，负责政府业务和多个真实世界行业的大客户。Netic 构建AI系统来运营真实世界的服务企业——从客户首次来电/短信/网站访问，到理解需求、匹配服务人员、调度派单，全部由 agent 处理。目前超过70%的客户已实现"Netic first"——消费者与企业的首次互动完全由 Netic agent 完成。

Tokmak 选择做平台而非PE收购 rollup 的三个原因：一是她想做可规模化复利的产品，而不是服务已收购的公司；二是她的技能组合是工程师+产品经理，而非M&A专家；三是平台模式可以服务所有行业，而 rollup 的产品只能服务已收购的那几家。

她对大实验室（OpenAI、Anthropic等）的看法颇为直接：不认为它们是竞争威胁，因为"OpenAI 建产品很快，杀产品也很快"，而传统企业客户不想要这种快节奏迭代。更重要的是，实验室研究者追求的是最通用化的解法（"等AGI来了再解决"），而她认为这种思维在操作层面和智力层面都有点懒惰——真实世界的问题需要最后一公里的 harness、编排、软件和产品能力，这些无法仅靠模型解决。

在人才招聘上，Tokmak 极其看重 agency（主动性/行动力）。她的面试杀手锏是问："你这辈子做过的最难的事是什么？"——不是为了听宏大叙事，而是看候选人是否在持续地展现主动性并坚持到底。她最近录用的一位工程师给出的答案是：十五年来每天严格执行健康作息，从未厌倦——这被她认为是一种极具创造力的 agency 表达。

Netic 已为客户创造了超过6亿美元的收入，全部来自AI处理的交互。Tokmak 对AI最大的兴奋点不在商业，而在教育——她本人来自土耳其小镇，靠奖学金进入斯坦福，深知技术如何改变没有资源的人的人生轨迹。
