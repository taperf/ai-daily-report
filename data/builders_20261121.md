## Matt Turck ， FirstMark Capital 合伙人，MAD Podcast 主理人

FirstMark 的 Matt Turck 用一个小故事讲完了「自动化 agent 外联」的现状：某人为了在 Slush 会议上见他，先发了两封邮件，他回了一封；对方紧接着又连发三封，让他觉得「这人是真的很想见面」。当天晚些时候他正好碰到对方，说「看来是注定要见的」，结果对方盯着他的胸牌看了两遍，一脸空白，显然完全不知道他是谁，只说了句「哦你好」就走开了。这个故事的价值在于它精确地画出了 agent 规模化外联的虚假之处：任务被完成了，关系没有建立。

Scale solves delivery, not recognition. An agent can generate the persistence of someone who really wants to meet you while the human behind it has no idea who you are, and that gap is now detectable in a single name-tag glance.

> 规模化解决的是送达，不是认识。agent 可以伪造出「真的很想见你」的执着感，而背后那个人根本不知道你是谁，这个落差现在只要扫一眼胸牌就会被发现。

## Latent Space: Scaling Linear's GTM to $100M ARR（Cristina Cordova, COO）

🔗 https://www.youtube.com/watch?v=x0VSm6IjcDQ

**The Takeaway:** Linear 上超过一半的 issue 现在由 agent 创建，而这发生在一家 CEO 刚公开写下「issue tracking is dead」的公司里；两者不矛盾，因为死掉的是「人手动跟踪工作」这件事，不是「issue」这个单位。

Cristina Cordova 是 Linear 的 COO，在此之前在 Notion 负责平台（API、合作与自助增长），更早在 Stripe 待了七年半，先做合作与 GTM，后转到产品侧为早期公司做新产品。她加入 Linear 时的公司只有约 40 人，年收入刚摸到中端市场天花板，最知名的身份是「对创业公司很好用的产品」。她的工作是把一家产品驱动增长的公司改造成能卖进更大组织的公司，同时不破坏让它好用的东西。

最有价值的不是增长数字，而是她讲的一套「先定义可解的问题」的方法。她入职三周后的全员会上，把公司三大目标里「进入企业市场」那一条当场划掉了，理由很简单：当时销售团队只有一个人，而用一个人去打企业是不可能的事。她把目标改成「攻下成长期（growth segment）公司」，也就是那些已经装了竞品、必须被说服把旧工具拆掉换成 Linear 的公司，并说如果能做到这一步，才有一到两年后进军企业的信心。直到 2025 年，她才第一次站在全员面前说「我们今年要做企业市场」。

关于 AI 对产品的影响，她给的数字最硬：Linear 在 2025 年上线 MCP server，是所在赛道里第一个做的，如今超过一半的 issue 由 agent 创建，仅仅用了一年半。她明确反对一种流行做法：把自己变成一个数据库、开一个 MCP server、把数据都交给 agent，然后指望 agent 来跟你互操作。她的理由是，你必须把 agentic 工作流做进自己的工具里，并且做得比用户在外面自己接的那套更好，否则人们没有理由再进你的产品。同时她观察到 app 内使用量也在同步上升，因为聊天界面不适合可视化一个团队的全部工作，而且是单人游戏，不适合协作。

她对「用 AI 省钱」这条路的边界讲得也很克制。Linear 没有 SDR，理由是客户不想花 30 分钟回答「你们公司多大、打算付多少钱」才能看到一个 demo；客服不外包，但 AI 只负责起草回复，由人类判断好坏，不做那种「LLM 先全部答一遍，客户生气回信了再上人」的模式。她承认这些工具让团队不必随业务线性增长，但明确说这不是裁员，是「没有按原本的速度扩招」。

两个有趣的细节。一是定价：Linear 从纯按席位收费，逐步加入按用量计费的新功能（跑 coding session、让 agent 扫全 backlog），做法是把 API 成本透明地加一点差价，聊天对话保持免费；她说公司倾向于一开始定得偏贵再往下调，而不是先便宜后涨价。二是她招人时做的是一份真正的 6 到 12 个月的工作试用项目，而不是假案例；被问到如果可以回到 2023 年会对当时的自己说什么，她的回答是「冷静点，一切都会好的」，并解释那年刚好是创业公司的寒冬，ChatGPT 刚出，融资极难。
