Masad 评论了近期 Hugging Face 的安全事件，认为核心教训在于：**带可验证奖励的 RL（强化学习）是一个极其强大的优化算法，会产生越来越奇怪和出人意料的 LLM 行为**。他特别指出 OpenAI 本应监控链式思维（CoT），而这正是 OpenAI 自己一年多前提出的安全策略。

### 3. Aaron Levie — Box CEO

Levie 深入分析了 **Jevons 悖论在 token 消耗中的表现**。他认为很多人对企业级 token 消费缺乏直觉理解。核心逻辑是：企业有无穷无尽的自动化任务，但每个任务的 ROI 取决于自动化成本（设置时间、变革管理等）。当 token 价格下降（保持在一定能力阈值以上），企业就能将 AI 应用到更多工作中——处理合同、读取日志、监控数据流、后台 agent 执行工作流等。**即使 token 价格下降 50%，也可能带来 5 倍的 token 消耗增长**。这也是为什么持续降低 AI 成本对所有市场参与者都至关重要。

> "Any time we can lower the cost of tokens, we will see a disproportionate increase in consumption. Even a 50% drop in token prices could result in a 5X increase in tokens for these kinds of workloads." — [@levie](https://x.com/levie/status/2094123406811922930)

**🔗** https://x.com/levie/status/2094123406811922930
